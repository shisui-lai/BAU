## 明确需求
屏蔽以下在“使能簇硬件故障汇总”中重复显示的故障项：
- 主正高边驱动反馈故障
- 主负高边驱动反馈故障
- 预充高边驱动反馈故障
- BMU设备通讯故障
- BCU通讯故障
- AFE通讯失联
- 单体电池掉线
- 单体温度探头掉线

## 方案
- 仅在渲染层对“使能簇硬件故障汇总”做局部过滤，不改协议字段表与CSV/其它页面。
- 在 `src/renderer/src/composables/core/data-processing/common/useFaultOverview.js` 中：
  1) 新增 `IGNORED_EN_CLUSTER_HW_FAULT_LABELS`（按中文标签匹配）或映射到内部键后按键过滤；优先使用内部键过滤以避免多语言影响。
  2) 在构建 `processedEnClusterHardwareSum` 时，遇到映射后的键在忽略清单中则跳过。

## 实施细节
- 通过现有 `labelToKeyMap[label]` → `key`：
  - 主正高边驱动反馈故障 → `MainPosHighSideDrvFeedbackFault`
  - 主负高边驱动反馈故障 → `MainNegHighSideDrvFeedbackFault`
  - 预充高边驱动反馈故障 → `PrechargeHighSideDrvFeedbackFault`
  - BMU设备通讯故障 → `BMUCommLost`
  - BCU通讯故障 → `BCUCommLost`
  - AFE通讯失联 → `AFECommLost`
  - 单体电池掉线 → `CellOffline`
  - 单体温度探头掉线 → `TempProbeOffline`
- 定义：`const IGNORED_EN_CLUSTER_HW_FAULT_KEYS = new Set([上述键])`
- 过滤：
```js
const key = labelToKeyMap[label]
if (IGNORED_EN_CLUSTER_HW_FAULT_KEYS.has(key)) continue
```

## 验证
- 打开故障预览页（Block/FaultOverview.vue），确认“使能簇硬件故障汇总”未显示上述8项；其它项与颜色不变。
- 列表页与CSV导出保持原样，未受影响。

## 说明
- 选择渲染层过滤可避免全局副作用；如后续需要在列表页也屏蔽，可在 `parseFault.ts` 或 `clusterStore.filterFaultData` 增加同名单独开关。
