## 目标
- 在“系统时间与记录”页面下新增“最近100条事件”容器，以 JS 文件实现。
- 仅在事件导出完成后一次性显示，并保证显示数据为“最新的100条”（若实际少于100条则以实际为准）。

## 现状与数据源
- 导出读取与缓存：`src/main/eventRecordExport.js` 完成批量读取与 `eventRecordDataCache` 缓存。
  - 读取入口：`startReadingEvent(...)`（`src/main/eventRecordExport.js:258`）。
  - 响应处理：`processEventRecordResponse(...)`（`src/main/eventRecordExport.js:133`）。
  - 完成通知：`stopReadingEvent(...)` → `readEventCompleted`（`src/main/eventRecordExport.js:510`）。
  - CSV生成：`generateEventRecordCSV(...)`（`src/main/eventRecordExport.js:530`）。
- 事件页面导出 UI：`src/renderer/src/views/Bau/eventRecord/event.vue`（监听 `export-completed`）。
- 字段定义/格式化：`EVENT_RECORD_R` 与 `formatEventRecordField(...)`（`src/protocol/eventRecordFormatter.js`）。

## 后端改动（主/子进程）
- 在 `stopReadingEvent(...)` 的“完成”分支（`src/main/eventRecordExport.js:471-520`）增加一次性回传“最近100条”数据：
  - 从 `eventRecordDataCache` 取按 `recordIndex` 排序的最后100条（如果 `totalRequested < 100`，则取 `totalRequested` 条；保证“最新”来源于本次导出的请求区间，即 `offsetRead + totalRead - 100 .. offsetRead + totalRead - 1`）。
  - 对每条使用 `formatEventRecordField(...)` 生成展示值，并合成 `Timestamp`（参考导出中的合成：`src/main/eventRecordExport.js:755-772`）。
  - 通过 `process.send({ type: 'readEventRecentFinal', data: { blockId, rows } })` 将 100 条的精简行对象一次性发送给主进程；主进程再 `webContents.send('recent-event-final', { blockId, rows })` 给渲染层。
  - 不在导出过程中进行任何批次推送，严格满足“导出完成后显示”。

## 前端改动（渲染层）
- 新增 JS Store：`src/renderer/src/stores/recentEventsStore.js`
  - 状态：`items: [], blockId: null`（容量上限100）。
  - 动作：`setRows(blockId, rows)`（覆盖为最新100条）、`clear()`、`persist()`（`localStorage`）。
  - Getter：`list` 返回展示数组。
- 在 `event.vue` 新增“最近100条事件”容器（位于“事件记录读取”卡片下）：
  - 表格列：`时间戳/事件类型/参数1/参数2/参数3/参数4/软件版本号/SOX算法版本号/退并簇算法版本号/网卡2 IP地址/堆运行状态/堆总故障/允充允放状态`。
  - 仅在收到 `recent-event-final` IPC 后渲染；支持清空与再次导出后覆盖更新。
- IPC监听：
  - 在 `event.vue` 监听 `recent-event-final`，调用 `recentEventsStore.setRows(blockId, rows)` 并 `persist()`；`onMounted` 从 `localStorage` 恢复。
  - 保持现有导出流程与进度监听不变。

## 显示“最新100条”的保证
- 由后端在完成时按“本次导出所请求区间的末尾100条”截取，确保是“最新的100条”（对应该次导出参数 `offsetRead + totalRead` 的尾段）。
- 若用户选择“全部导出”，则按设备返回的总数尾段100条；若用户输入 `valueRead=100`（页面默认值已有：`src/renderer/src/views/Bau/eventRecord/event.vue:301`），则本次导出的全部即为“最新100条”。

## 验证步骤
- 触发一次导出（默认读取100条）。导出完成后：
  - 容器显示 100 条（或实际读取数）并与 CSV 中相同记录一致。
  - 切换堆或再次导出时，容器更新为新数据；刷新页面后仍可从缓存恢复。

## 兼容与注意事项
- `NetworkCard2IPAddress` 当前为单字节值，暂以原值显示；后续若协议提供多字节组合再在格式化器补充。
- 仅在“完成”事件后渲染，避免过程中显示半成品数据。
