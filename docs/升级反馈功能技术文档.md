## 功能概述

升级反馈功能用于实时查询和显示BAU、BCU、BMU三种设备升级的执行结果。系统通过MQTT协议定期轮询设备升级状态，解析返回的二进制数据，并在UI上实时展示。

### 支持的升级类型
- **BAU升级**: 堆级升级，查询单个堆的升级结果
- **BCU升级**: 簇级升级，可同时查询多个簇的升级结果
- **BMU升级**: 簇级升级，可同时查询多个簇的升级结果，并显示下载进度

### 核心特性
1. **独立轮询机制**: 每种升级类型都有独立的轮询定时器，互不干扰
2. **多簇动态查询**: BCU/BMU升级支持根据用户选择的簇动态生成查询列表
3. **实时数据更新**: 1秒轮询间隔，实时反馈升级状态
4. **条件显示**: 根据升级类型动态显示不同的字段

## 数据流程

### 1. 轮询启动流程

```
用户点击"开始升级"
    ↓
bauUpgrade.vue: startUpgrade()
    ↓
调用 startUpgradeResultPollingByType()
    ↓
根据升级类型启动对应的轮询:
  - BAU升级: startBauUpgradeResultPolling(getBlockId)
  - BCU/BMU升级: startBcuBmuUpgradeResultPolling(clusterKeys)
    ↓
useRemoteCommand.js: executeBauUpgradeResultQuery() 或 executeBcuBmuUpgradeResultQuery()
    ↓
通过 window.electronAPI.mqttPublish() 发送MQTT消息
    ↓
MQTT子进程: 发布查询消息到设备
```

### 2. 响应接收流程

```
设备返回MQTT响应
    ↓
MQTT子进程: mqtt.js 接收消息
    ↓
根据topic在TOPIC_TABLE_MAP中查找解析函数
    ↓
调用 parseBauUpgradeResultRAW() 或 parseBcuBmuUpgradeResultRAW()
    ↓
使用 parseByTable() 解析二进制数据
    ↓
根据 table.js 中的字段定义和映射表转换数据
    ↓
返回解析结果对象
    ↓
MQTT子进程: 通过IPC发送到主进程
    ↓
主进程: index.js 接收并转发到渲染进程
    ↓
渲染进程: bauUpgrade.vue 的 handleUpgradeResultResponse() 接收
    ↓
调用 useRemoteCommand.js: handleFeedbackQueryResponse()
    ↓
更新 feedbackStatus 响应式状态
    ↓
UI自动更新显示
```

### 1. 字段定义 (`src/main/table.js`)

#### BAU升级结果字段 (6字节)

```javascript
export const BAU_UPGRADE_RESULT_FIELDS = [
  // offset 0: 升级文件下载完成标志 (uint16_t)
  { key: 'downloadCompleteFlag', type: 'u16', map: DOWNLOAD_COMPLETE_FLAG_MAP },
  
  // offset 2: OTA文件下载错误码 (uint16_t)
  { key: 'otaErrorCode', type: 'u16', map: OTA_ERROR_CODE_MAP },
  
  // offset 4: BAU升级故障码 (uint16_t)
  { key: 'bauFaultCode', type: 'u16', map: BAU_FAULT_CODE_MAP }
]
```

#### BCU/BMU升级结果字段 (20字节)

```javascript
export const BCU_BMU_UPGRADE_RESULT_FIELDS = [
  // offset 0: 升级设备类型 (uint16_t)
  { key: 'deviceType', type: 'u16', map: UPGRADE_DEVICE_TYPE_MAP },
  
  // offset 2: 升级文件下载完成标志 (uint16_t)
  { key: 'downloadCompleteFlag', type: 'u16', map: DOWNLOAD_COMPLETE_FLAG_MAP },
  
  // offset 4: 升级完成类型 (uint16_t)
  { key: 'completionType', type: 'u16', map: UPGRADE_COMPLETION_TYPE_MAP },
  
  // offset 6: OTA文件下载错误码 (uint16_t)
  { key: 'otaErrorCode', type: 'u16', map: OTA_ERROR_CODE_MAP },
  
  // offset 8: BCU升级故障码 (uint16_t)
  { key: 'bcuFaultCode', type: 'u16', map: BCU_FAULT_CODE_MAP },
  
  // offset 10: BMU升级故障码 (uint16_t)
  { key: 'bmuFaultCode', type: 'u16', map: BMU_FAULT_CODE_MAP },
  
  // offset 12-15: BMU升级失败设备标识 (uint32_t, bitmask)
  { key: 'bmuFailedDevicesRaw', type: 'u32' },
  
  // offset 16: BMU程序总包数 (uint16_t)
  { key: 'totalPackets', type: 'u16' },
  
  // offset 18: BMU下载当前包序号 (uint16_t, 0-based)
  { key: 'currentPacket', type: 'u16' }
]
```

#### 映射表定义

- **OTA_ERROR_CODE_MAP**: OTA文件下载错误码映射 (0x0000-0x000F + BAU特有 0x0010-0x0013)
- **BCU_FAULT_CODE_MAP**: BCU升级故障码映射 (0x0000-0x000F)
- **BMU_FAULT_CODE_MAP**: BMU升级故障码映射 (0x0000, 0x0001-0x0009 BMU特有, 0x000A-0x000F)
- **BAU_FAULT_CODE_MAP**: BAU升级故障码映射 (0x0000-0x000F + 0x0010-0x0013 BAU特有)
- **DOWNLOAD_COMPLETE_FLAG_MAP**: 下载完成标志映射 (0x0000: '未知', 0x5BB5: '下载完成')

### 2. 协议解析 (`src/protocol/utils.js`)

#### parseBauUpgradeResultRAW()

```javascript
export function parseBauUpgradeResultRAW(payload) {
  // 1. 转换payload为Buffer
  const buf = Buffer.isBuffer(payload) ? payload : Buffer.from(String(payload).replace(/\s+/g, ''), 'hex')
  
  // 2. 处理空响应
  if (buf.length === 0) { return { error: true, message: '空响应' } }
  
  // 3. 处理1字节错误响应
  if (buf.length === 1) { return { error: true, code: buf[0] } }
  
  // 4. 处理6字节成功响应
  if (buf.length === 6) {
    const view = dv(buf)
    const { baseConfig } = parseByTable(view, BAU_UPGRADE_RESULT_FIELDS, 0)
    
    // 提取字段（带map的字段返回{raw, txt}格式）
    const downloadCompleteFlag = baseConfig.downloadCompleteFlag
    const otaErrorCode = baseConfig.otaErrorCode
    const bauFaultCode = baseConfig.bauFaultCode
    
    return {
      error: false,
      commandType: 'query_command',
      topic: 'get_bau_upgrade_result',
      data: {
        downloadCompleteFlagRaw: typeof downloadCompleteFlag === 'object' ? downloadCompleteFlag.raw : downloadCompleteFlag,
        otaErrorCodeRaw: typeof otaErrorCode === 'object' ? otaErrorCode.raw : otaErrorCode,
        bauFaultCodeRaw: typeof bauFaultCode === 'object' ? bauFaultCode.raw : bauFaultCode,
        downloadCompleteFlag: typeof downloadCompleteFlag === 'object' ? downloadCompleteFlag.txt : downloadCompleteFlag,
        otaErrorCode: typeof otaErrorCode === 'object' ? otaErrorCode.txt : otaErrorCode,
        bauFaultCode: typeof bauFaultCode === 'object' ? bauFaultCode.txt : (bauFaultCode === 0 ? '无故障' : `故障码: 0x${bauFaultCode.toString(16).toUpperCase()}`),
        success: true
      }
    }
  }
  
  // 5. 其他长度返回错误
  return { error: true, message: `未知响应长度: ${buf.length}` }
}
```

```javascript
    // 提取所有字段
    const deviceType = baseConfig.deviceType
    const downloadCompleteFlag = baseConfig.downloadCompleteFlag
    const completionType = baseConfig.completionType
    const otaErrorCode = baseConfig.otaErrorCode
    const bcuFaultCode = baseConfig.bcuFaultCode
    const bmuFaultCode = baseConfig.bmuFaultCode
    const bmuFailedDevicesRaw = baseConfig.bmuFailedDevicesRaw
    const totalPackets = baseConfig.totalPackets

    // 解析BMU失败设备列表（从bitmask）

    return {
      error: false,
      commandType: 'query_command',
      topic: 'get_bcu_bmu_upgrade_result',
      data: {
        // 原始值
        deviceTypeRaw: typeof deviceType === 'object' ? deviceType.raw : deviceType,
        downloadCompleteFlagRaw: typeof downloadCompleteFlag === 'object' ? downloadCompleteFlag.raw : downloadCompleteFlag,
        // ... 其他字段类似
        // 解析后的文本值（有map的字段使用txt，否则使用原始值）
        deviceType: typeof deviceType === 'object' ? deviceType.txt : deviceType,
        downloadCompleteFlag: typeof downloadCompleteFlag === 'object' ? downloadCompleteFlag.txt : downloadCompleteFlag,
        // ... 其他字段类似
        bmuFailedDevices,
        totalPackets,
        currentPacket,
        success: true
      }
    }
  }
  
  // 5. 其他长度返回错误
  return { error: true, message: `未知响应长度: ${buf.length}` }
}
```

```javascript
// 启动BAU升级结果轮询
function startBauUpgradeResultPolling(getBlockId) {
  if (bauUpgradeResultPollingActive.value) {
    return
  }
  
  bauUpgradeResultPollingActive.value = true
  
  // 立即执行一次查询
  const blockId = getBlockId()
  executeBauUpgradeResultQuery(blockId)
  
  // 启动定时器，每1秒查询一次
  bauUpgradeResultPollingTimer = setInterval(() => {
    const currentBlockId = getBlockId()
    executeBauUpgradeResultQuery(currentBlockId)
  }, 1000)
}

async function executeBauUpgradeResultQuery(blockId) {
  const config = getCommandConfig('get_bau_upgrade_result')
  const topic = `bms/host/s2d/b${blockId}/${config.topic}`
  const payload = 'ff'
  await window.electronAPI.mqttPublish(topic, payload)
}
```

```javascript
// 启动BCU/BMU升级结果多簇轮询
function startBcuBmuUpgradeResultPolling(clusterKeys) {
  if (bcuBmuUpgradeResultPollingActive.value) {
    return
  }
  
  if (!clusterKeys || clusterKeys.length === 0) {
    return
  }
  
  bcuBmuUpgradeResultPollingActive.value = true
  
  // 立即执行一次批量查询
  clusterKeys.forEach(clusterKey => {
    executeBcuBmuUpgradeResultQuery(clusterKey)
  })
  
  // 启动定时器，每1秒批量查询一次
  bcuBmuUpgradeResultPollingTimer = setInterval(() => {
    clusterKeys.forEach(clusterKey => {
      executeBcuBmuUpgradeResultQuery(clusterKey)
    })
  }, 1000)
}

// 执行单个簇的BCU/BMU升级结果查询
async function executeBcuBmuUpgradeResultQuery(clusterKey) {
  const config = getCommandConfig('get_bcu_bmu_upgrade_result')
  const [blockId, clusterId] = clusterKey.split('-').map(Number)
  const topic = `bms/host/s2d/b${blockId}/c${clusterId}/${config.topic}`
  const payload = 'ff'
  await window.electronAPI.mqttPublish(topic, payload)
}
```

#### 响应处理函数

```javascript
function handleFeedbackQueryResponse(commandId, responseData) {
  if (!responseData || responseData.error) {
    return
  }
  
  switch (commandId) {
    case 'get_bcu_bmu_upgrade_result':
      // 从MQTT响应Topic中解析 blockId 和 clusterId
      const topic = responseData.topic || ''
      const topicMatch = topic.match(/b(\d+)\/c(\d+)\//)
      let blockId, clusterId
      
      if (topicMatch) {
        blockId = parseInt(topicMatch[1])
        clusterId = parseInt(topicMatch[2])
      } else {
        blockId = responseData.blockId
        clusterId = responseData.clusterId
      }
      
      if (blockId && clusterId) {
        const clusterKey = `${blockId}-${clusterId}`
        
        if (responseData.data && typeof responseData.data === 'object' && !responseData.error) {
          // 更新Map中对应簇的结果
          feedbackStatus.bcu_bmu_upgrade_result.set(
            clusterKey,
            parseBcuBmuUpgradeResult(responseData.data)
          )
        } else {
          // 删除无效数据
          feedbackStatus.bcu_bmu_upgrade_result.delete(clusterKey)
        }
      }
      break
      
    case 'get_bau_upgrade_result':
      if (responseData.data && typeof responseData.data === 'object' && !responseData.error) {
        feedbackStatus.bau_upgrade_result = parseBauUpgradeResult(responseData.data)
      } else {
        feedbackStatus.bau_upgrade_result = null
      }
      break
  }
}
```

#### 数据解析函数

```javascript
// 解析BAU升级结果（将"未知"替换为"--"）
function parseBauUpgradeResult(data) {
  if (!data || data.error) {
    return null
  }
  
  const replaceUnknown = (value) => {
    if (typeof value === 'string' && (value === '未知' || value.includes('未知值'))) {
      return '--'
    }
    return value || '--'
  }
  
  return {
    downloadCompleteFlag: replaceUnknown(data.downloadCompleteFlag),
    downloadCompleteFlagRaw: data.downloadCompleteFlagRaw,
    otaErrorCode: replaceUnknown(data.otaErrorCode),
    otaErrorCodeRaw: data.otaErrorCodeRaw,
    bauFaultCode: replaceUnknown(data.bauFaultCode),
    bauFaultCodeRaw: data.bauFaultCodeRaw,
    timestamp: new Date()
  }
}

// 解析BCU/BMU升级结果（将"未知"替换为"--"，currentPacket从0-based转为1-based）
function parseBcuBmuUpgradeResult(data) {
  if (!data || data.error) {
    return null
  }
  
  const replaceUnknown = (value) => {
    if (typeof value === 'string' && (value === '未知' || value.includes('未知值'))) {
      return '--'
    }
    return value || '--'
  }
  
  return {
    deviceType: replaceUnknown(data.deviceType),
    deviceTypeRaw: data.deviceTypeRaw,
    downloadCompleteFlag: replaceUnknown(data.downloadCompleteFlag),
    downloadCompleteFlagRaw: data.downloadCompleteFlagRaw,
    completionType: replaceUnknown(data.completionType),
    completionTypeRaw: data.completionTypeRaw,
    otaErrorCode: replaceUnknown(data.otaErrorCode),
    otaErrorCodeRaw: data.otaErrorCodeRaw,
    bcuFaultCode: replaceUnknown(data.bcuFaultCode),
    bcuFaultCodeRaw: data.bcuFaultCodeRaw,
    bmuFaultCode: replaceUnknown(data.bmuFaultCode),
    bmuFaultCodeRaw: data.bmuFaultCodeRaw,
    bmuFailedDevices: data.bmuFailedDevices || [],
    bmuFailedDevicesRaw: data.bmuFailedDevicesRaw,
    totalPackets: data.totalPackets || 0,
    totalPacketsRaw: data.totalPacketsRaw,
    // currentPacket从0-based转换为1-based
    currentPacket: ((data.currentPacket || 0) + 1),
    currentPacketRaw: data.currentPacketRaw,
    timestamp: new Date()
  }
}
```

```javascript
  stopBcuBmuUpgradeResultPolling()
```

```javascript
  feedbackStatus.bcu_bmu_upgrade_result.clear()
  feedbackStatus.bau_upgrade_result = null
  
  const upgradeType = selectedUpgrade.value
  
  if (upgradeType === '0xA000') {
    // BAU升级：启动BAU轮询
    const getBlockId = () => selectedBlock.value || 1
    startBauUpgradeResultPolling(getBlockId)
  } else if (upgradeType === '0xA001' || upgradeType === '0xA002') {
    // BCU/BMU升级：同时启动BAU轮询和BCU/BMU多簇轮询
    const getBlockId = () => selectedBlock.value || 1
    startBauUpgradeResultPolling(getBlockId) // BAU轮询用于检查BAU的下载状态
    
    // 计算需要查询的簇列表
    const blockClusterKeys = computed(() => {
      // 根据用户选择的全局簇ID和系统拓扑，映射到block-cluster格式
      return mapGlobalClustersToBlockClusters(selectedGlobalClusters.value)
    })
    
    startBcuBmuUpgradeResultPolling(blockClusterKeys.value)
  }
```

## 数据格式说明

### MQTT Topic格式

#### BAU升级结果查询
- **发布Topic**: `bms/host/s2d/b{blockId}/get_bau_upgrade_result`
- **订阅Topic**: `bms/bau/d2s/b{blockId}/get_bau_upgrade_result`
- **Payload**: `ff` (查询命令)

#### BCU/BMU升级结果查询
- **发布Topic**: `bms/host/s2d/b{blockId}/c{clusterId}/get_bcu_bmu_upgrade_result`
- **订阅Topic**: `bms/bau/d2s/b{blockId}/c{clusterId}/get_bcu_bmu_upgrade_result`
- **Payload**: `ff` (查询命令)

### 响应数据格式

#### BAU升级结果响应 (6字节)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | 升级文件下载完成标志 | uint16_t | 0x0000: 未知, 0x5BB5: 下载完成 |
| 2-3 | 2 | OTA文件下载错误码 | uint16_t | 参见OTA_ERROR_CODE_MAP |
| 4-5 | 2 | BAU升级故障码 | uint16_t | 参见BAU_FAULT_CODE_MAP |

#### BCU/BMU升级结果响应 (20字节)

| 偏移 | 长度 | 字段名 | 类型 | 说明 |
|------|------|--------|------|------|
| 0-1 | 2 | 升级设备类型 | uint16_t | 参见UPGRADE_DEVICE_TYPE_MAP |
| 2-3 | 2 | 升级文件下载完成标志 | uint16_t | 0x0000: 未知, 0x5BB5: 下载完成 |
| 4-5 | 2 | 升级完成类型 | uint16_t | 参见UPGRADE_COMPLETION_TYPE_MAP |
| 6-7 | 2 | OTA文件下载错误码 | uint16_t | 参见OTA_ERROR_CODE_MAP |
| 8-9 | 2 | BCU升级故障码 | uint16_t | 参见BCU_FAULT_CODE_MAP |
| 10-11 | 2 | BMU升级故障码 | uint16_t | 参见BMU_FAULT_CODE_MAP |
| 12-15 | 4 | BMU升级失败设备标识 | uint32_t | Bitmask，每个bit代表一个BMU设备 |
| 16-17 | 2 | BMU程序总包数 | uint16_t | 总包数 |
| 18-19 | 2 | BMU下载当前包序号 | uint16_t | 0-based，显示时需要+1 |

## 总结

升级反馈功能通过以下关键技术实现：

1. **表驱动解析**: 使用`parseByTable`和字段定义表实现灵活的二进制数据解析
2. **映射表转换**: 通过映射表将原始数值转换为可读文本
3. **独立轮询机制**: 每种升级类型都有独立的轮询定时器，支持不同的查询策略
4. **多簇动态查询**: BCU/BMU升级根据用户选择和系统拓扑动态生成查询列表
5. **响应式状态管理**: 使用Vue的响应式系统实现UI自动更新
6. **条件显示**: 根据升级类型动态显示不同的字段

该功能完整实现了BAU、BCU、BMU三种升级类型的实时反馈，具有良好的可扩展性和维护性。
