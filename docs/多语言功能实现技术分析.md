### 2.2 实现原理详解

#### 📦 第一步：依赖安装

**文件**: `package.json`

```json
{
  "dependencies": {
    "vue-i18n": "^11.1.12"  // Vue国际化核心库
  },
  "devDependencies": {
    "@intlify/unplugin-vue-i18n": "^11.0.1",  // Vite构建插件
    "electron-store": "^11.0.2"  // 持久化存储
  }
}
```

**作用**：
- `vue-i18n`: 提供 `createI18n()` 和 `useI18n()` 等API
- `@intlify/unplugin-vue-i18n`: 在构建时自动处理语言文件
- `electron-store`: 在Electron主进程中保存用户选择的语言

---

#### ⚙️ 第二步：构建配置

**文件**: `electron.vite.config.mjs`

```javascript
import VueI18nPlugin from '@intlify/unplugin-vue-i18n/vite'

export default defineConfig({
  renderer: {
    plugins: [
      vue(),
      VueI18nPlugin({
        // 告诉插件去哪里找语言文件
        include: [resolve(__dirname, './src/renderer/src/locales/**')]
      })
    ]
  }
})
```

**工作原理**：
1. Vite在构建时扫描 `locales/` 目录
2. 自动读取所有 `.json` 语言文件
3. 将它们打包成一个 `messages` 对象
4. 在运行时可以通过 `import messages from '@intlify/unplugin-vue-i18n/messages'` 导入

**为什么能自动加载？**
- 插件在编译时做了代码转换
- 把所有语言文件合并成一个JavaScript模块
- 这就是为什么我们不需要手动 `import zh from './locales/zh.json'`

---

#### 🖥️ 第三步：主进程配置

**文件**: `src/main/index.js`

```javascript
// 1. 导入electron-store（延迟加载）
let store
async function initStore() {
  const mod = await import('electron-store')
  const Store = mod.default
  store = new Store({ 
    defaults: { locale: 'zh' }  // 默认语言是中文
  })
}

// 2. 注册IPC处理器 - 获取语言
ipcMain.handle('get-locale', () => {
  return store.get('locale')  // 从存储中读取
})

// 3. 注册IPC处理器 - 设置语言
ipcMain.handle('set-locale', (_event, locale) => {
  store.set('locale', locale)  // 保存到存储
})

// 4. 应用启动时初始化
app.whenReady().then(async () => {
  await initStore()  // 先初始化存储
  // ... 其他初始化代码
})
```

**electron-store 工作原理**：
- 在用户的系统中创建一个JSON配置文件
- Windows: `C:\Users\用户名\AppData\Roaming\你的应用名\config.json`
- 内容类似: `{ "locale": "zh" }`
- 应用重启后仍然能读取到

**IPC通信原理**：
```
渲染进程 ──────> 主进程
         get-locale
         
渲染进程 <────── 主进程
         返回 "zh"
```

#### 🔌 第四步：Preload桥接

**文件**: `src/preload/index.js`

```javascript
contextBridge.exposeInMainWorld('electronAPI', {
  // 暴露获取语言的API
  getLocale: () => ipcRenderer.invoke('get-locale'),
  
  // 暴露设置语言的API
  setLocale: (locale) => ipcRenderer.invoke('set-locale', locale)
})
```

**contextBridge 是什么？**
- Electron的安全机制
- 渲染进程默认无法访问Node.js API
- contextBridge创建一个安全的桥梁
- 把主进程的功能暴露给渲染进程

**为什么需要Preload？**
```
┌──────────────┐         ┌──────────────┐
│  渲染进程     │  ❌    │   主进程      │
│  (网页环境)  │ 无法   │  (Node.js)   │
│              │ 直接   │              │
│              │ 访问   │              │
└──────────────┘         └──────────────┘

         ↓ 通过 contextBridge ↓

┌──────────────┐         ┌──────────────┐
│  渲染进程     │  ✅    │   主进程      │
│              │ 安全   │              │
│ window.      │ 调用   │ ipcMain      │
│ electronAPI  │        │              │
└──────────────┘         └──────────────┘
```

#### 🎨 第五步：渲染进程初始化

**文件**: `src/renderer/src/main.js`

```javascript
// 1. 导入必要的库
import { createI18n } from 'vue-i18n'
import messages from '@intlify/unplugin-vue-i18n/messages'

// 2. 创建Vue应用
const app = createApp(App)

// 3. 异步初始化函数
async function bootstrap() {
  // 3.1 获取用户上次选择的语言
  let defaultLocale = 'zh'
  
  if (window.electronAPI?.getLocale) {
    // Electron环境：从主进程获取
    defaultLocale = await window.electronAPI.getLocale()
  } else {
    // 浏览器环境：从localStorage获取
    const saved = localStorage.getItem('locale')
    if (saved) defaultLocale = saved
  }

  // 3.2 创建i18n实例
  const i18n = createI18n({
    legacy: false,           // 使用Composition API模式
    locale: defaultLocale,   // 设置当前语言
    fallbackLocale: 'en',    // 找不到翻译时使用英文
    messages                 // 语言包数据
  })
  
  // 3.3 注册i18n插件
  app.use(i18n)
  
  // 3.4 挂载应用
  app.mount('#app')
}

// 4. 启动应用
bootstrap()
```

**为什么要异步初始化？**
- `window.electronAPI.getLocale()` 是异步操作
- 需要等待主进程返回结果
- 所以必须用 `async/await`

**messages 对象结构**：
```javascript
{
  zh: {
    login: {
      title: "系统登录",
      username: "用户名"
    }
  },
  en: {
    login: {
      title: "System Login",
      username: "Username"
    }
  }
}
```

#### 🧩 第七步：语言切换组件

**文件**: `src/renderer/src/components/LangSelect.vue`

```vue
<template>
  <div class="locale-switcher">
    <select v-model="currentLocale" @change="changeLocale">
      <option v-for="loc in locales" :key="loc" :value="loc">
        {{ loc }}
      </option>
    </select>
  </div>
</template>

<script setup>
import { ref } from 'vue'
import { useI18n } from 'vue-i18n'

// 1. 获取i18n实例
const { locale, availableLocales } = useI18n()

// 2. 可用语言列表
const locales = availableLocales.value || ['zh', 'en']

// 3. 当前选中的语言
const currentLocale = ref(locale.value)

// 4. 初始化：从存储读取
const initLocale = async () => {
  let saved = null
  
  if (window.electronAPI && window.electronAPI.getLocale) {
    saved = await window.electronAPI.getLocale()
  } else {
    saved = localStorage.getItem('locale')
  }
  
  if (saved && locales.includes(saved)) {
    locale.value = saved
    currentLocale.value = saved
  }
}

// 5. 切换语言
const changeLocale = async () => {
  // 5.1 更新i18n的当前语言
  locale.value = currentLocale.value
  
  // 5.2 持久化保存
  if (window.electronAPI && window.electronAPI.setLocale) {
    await window.electronAPI.setLocale(currentLocale.value)
  } else {
    localStorage.setItem('locale', currentLocale.value)
  }
}

// 6. 组件挂载时初始化
initLocale()
</script>
```

**useI18n() 返回什么？**
```javascript
{
  locale: Ref<string>,           // 当前语言，响应式
  availableLocales: Ref<string[]>, // 可用语言列表
  t: Function                    // 翻译函数
}
```

**响应式原理**：
- `locale` 是Vue的响应式引用
- 当 `locale.value` 改变时
- 所有使用 `t()` 的地方自动更新

## 四、关键技术点解析

### 4.1 为什么使用 Composition API 模式？

```javascript
const i18n = createI18n({
  legacy: false  // 关键配置
})
```

**两种模式对比**：

| 特性 | Legacy模式 | Composition API模式 |
|------|-----------|-------------------|
| 使用方式 | `this.$t()` | `const { t } = useI18n()` |
| 适用版本 | Vue 2 风格 | Vue 3 风格 |
| 类型支持 | 较弱 | 强类型支持 |
| Tree-shaking | 不支持 | 支持 |

**我们选择Composition API因为**：
- 项目使用 Vue 3
- 更好的TypeScript支持
- 更小的打包体积

---

### 4.2 fallbackLocale 的作用

```javascript
const i18n = createI18n({
  locale: 'zh',
  fallbackLocale: 'en'  // 回退语言
})
```

**工作原理**：
```javascript
// 如果 zh.json 中缺少某个key
t('some.missing.key')
  ↓
在 messages.zh 中查找
  ↓
找不到！
  ↓
在 messages.en 中查找 (fallback)
  ↓
返回英文翻译或key本身
```

**好处**：
- 防止翻译缺失导致显示空白
- 开发时可以先写英文，后补中文

---

### 4.3 响应式更新原理

```javascript
// locale 是一个 Ref
const { locale } = useI18n()

// 改变语言
locale.value = 'en'
```

**Vue 3 响应式系统**：
```
locale.value 改变
  ↓
触发 effect (副作用)
  ↓
所有依赖 locale 的计算重新执行
  ↓
t() 函数返回新的翻译
  ↓
组件重新渲染
```

这就是为什么切换语言后，页面自动更新！

---

### 4.4 为什么需要 electron-store？

**问题**：如果只用 localStorage
```javascript
// 渲染进程
localStorage.setItem('locale', 'en')

// 重启应用
// 主进程无法读取 localStorage！
// 因为主进程不是浏览器环境
```

**解决方案**：electron-store
```javascript
// 主进程
store.set('locale', 'en')
// 写入文件系统

// 重启应用
store.get('locale')
// 从文件系统读取
// ✅ 可以正常工作
```
