# BAU上位机多语言国际化功能实施计划

## 文档说明
本文档基于 reference/modbus-src 项目的多语言实现方案，详细规划 BAU 上位机的英文翻译功能开发流程。

---

## 一、项目概述

### 1.1 目标
为 BAU 上位机系统添加完整的中英文双语支持，实现界面语言的动态切换。

### 1.2 技术方案
- **国际化库**: vue-i18n (版本 ^9.x)
- **构建插件**: @intlify/unplugin-vue-i18n
- **持久化存储**: electron-store
- **语言包格式**: JSON

### 1.3 参考项目
- **源项目**: `reference/modbus-src`
- **目标项目**: `src`

---

```javascript

app.use(pinia)
app.use(router)

// ... PrimeVue 等配置保持不变

// 修改为异步启动函数
async function bootstrap() {
  // 从 Electron 主进程获取用户语言偏好
  let defaultLocale = 'zh'
  
  if (window.electronAPI?.getLocale) {
    defaultLocale = await window.electronAPI.getLocale()
  } else {
    // 浏览器环境使用 localStorage
    const saved = localStorage.getItem('locale')
    if (saved) defaultLocale = saved
  }

  // 创建 i18n 实例
  const i18n = createI18n({
    legacy: false, // Composition API 模式
    locale: defaultLocale,
    fallbackLocale: 'en',
    messages
  })
  
  app.use(i18n)
  app.mount('#app')
}

// 启动应用
bootstrap()
```

### 阶段六：创建语言切换组件 ⏱️ 0.5天

#### 步骤 6.1：创建 langSelect.vue 组件
**操作**：创建独立的语言选择组件

**参考文件**：
- `reference/modbus-src/renderer/src/views/auth/langSelect.vue`

**创建文件**：`src/renderer/src/components/LangSelect.vue`

**完整代码**：
```vue
<template>
  <div class="locale-switcher">
    <Dropdown 
      v-model="currentLocale" 
      :options="localeOptions" 
      optionLabel="label"
      optionValue="value"
      @change="changeLocale"
      placeholder="选择语言"
    />
  </div>
</template>

<script setup>
import { ref, computed } from 'vue'
import { useI18n } from 'vue-i18n'
import Dropdown from 'primevue/dropdown'

const { locale, availableLocales } = useI18n()
const currentLocale = ref(locale.value)

// 语言选项
const localeOptions = computed(() => [
  { label: '中文', value: 'zh' },
  { label: 'English', value: 'en' }
])

// 初始化语言
const initLocale = async () => {
  let saved = null
  
  // Electron 环境
  if (window.electronAPI && window.electronAPI.getLocale) {
    saved = await window.electronAPI.getLocale()
  } else {
    saved = localStorage.getItem('locale')
  }
  
  if (saved && availableLocales.value.includes(saved)) {
    locale.value = saved
    currentLocale.value = saved
  }
}

// 切换语言
const changeLocale = async () => {
  locale.value = currentLocale.value
  
  // 持久化存储
  if (window.electronAPI && window.electronAPI.setLocale) {
    await window.electronAPI.setLocale(currentLocale.value)
  } else {
    localStorage.setItem('locale', currentLocale.value)
  }
}

// 初始化
initLocale()
</script>

<style scoped>
.locale-switcher {
  display: inline-block;
  min-width: 120px;
}
</style>
```

#### 步骤 9.2：在 App.vue 中监听菜单语言切换
**操作**：接收主进程的语言切换事件

**参考文件**：
- `reference/modbus-src/renderer/src/App.vue` (第 145-148, 176, 188 行)

**修改文件**：`src/renderer/src/layout/AppLayout.vue`

**添加代码**：
```vue
<script setup>
import { onMounted, onBeforeUnmount } from 'vue'
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

// 处理主进程发送的语言切换事件
const handleSetLocale = (_event, lang) => {
  locale.value = lang
  localStorage.setItem('locale', lang)
}

onMounted(() => {
  // 监听主进程的语言切换事件
  if (window.electron?.ipcRenderer) {
    window.electron.ipcRenderer.on('set-locale', handleSetLocale)
  }
})

onBeforeUnmount(() => {
  // 清理监听器
  if (window.electron?.ipcRenderer) {
    window.electron.ipcRenderer.removeListener('set-locale', handleSetLocale)
  }
})
</script>
```

## 四、常见问题解决方案

### 问题 1：切换语言后部分文本未更新
**原因**：使用了静态变量而非响应式引用

**解决方案**：
```javascript
// ❌ 错误
const config = {
  label: t('config.label') // 初始化后不会更新
}

// ✅ 正确
const config = computed(() => ({
  label: t('config.label') // 响应式更新
}))
```

### 问题 2：翻译 key 未找到
**原因**：key 路径错误或语言包缺失

**解决方案**：
1. 检查 key 拼写
2. 确认语言包中存在该 key
3. 使用 te() 函数先检查
```javascript
const text = te('some.key') ? t('some.key') : '默认文本'
```

### 问题 3：构建后语言包未打包
**原因**：vite 配置问题

**解决方案**：
检查 `electron.vite.config.mjs` 中的 VueI18nPlugin 配置：
```javascript
VueI18nPlugin({
  include: [resolve(__dirname, './src/renderer/src/locales/**')]
})
```

### 问题 4：Electron 环境无法获取 locale
**原因**：preload API 未正确暴露

**解决方案**：
检查 `src/preload/index.js` 中是否正确暴露：
```javascript
contextBridge.exposeInMainWorld('electronAPI', {
  getLocale: () => ipcRenderer.invoke('get-locale'),
  setLocale: (locale) => ipcRenderer.invoke('set-locale', locale)
})
```
