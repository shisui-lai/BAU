# 上位机数据监控系统技术架构文档

## 1. 系统概述

### 1.1 项目背景
本项目是一个基于Electron的上位机数据监控系统，专门用于监控和管理电池管理系统(BMS)设备。系统通过MQTT协议与下位机设备通信，实现实时数据采集、参数配置、故障监控等功能。

### 1.2 核心功能
- **实时数据监控**: 单体电压、温度、SOC、SOH等关键参数的实时显示
- **设备参数配置**: 支持系统基本参数、SOX参数、报警参数等的读取和配置
- **故障诊断**: 多级故障报警、故障历史记录和分析
- **数据可视化**: 图表展示、数据导出、历史数据查询
- **设备管理**: 堆/簇切换、设备状态监控、通信状态管理

### 1.3 技术栈选择
- **Electron**: 跨平台桌面应用，满足工业软件部署需求
- **Vue 3 + Composition API**: 现代化响应式框架，提供更好的代码组织
- **Pinia**: 轻量级状态管理，提供更好的TypeScript支持
- **PrimeVue**: 企业级UI组件库，满足工业软件界面需求
- **MQTT**: 轻量级消息传输协议，适合IoT设备通信
- **TypeScript**: 类型安全，提高代码质量和维护性

### 4.2 数据限流机制 (src/protocol/ipcThrottler.js)

#### 智能限流策略
- **前台模式**: 300ms限流，保证响应性
- **后台模式**: 5s限流，节省资源
- **动态切换**: 根据页面可见性自动调整

```javascript
export const THROTTLE_MS = 300     // 前台：300ms
const BACKGROUND_THROTTLE_MS = 5000  // 后台：5s

export function sendToParent(msg) {
  const key = makeKey(msg)
  const currentThrottleMs = isPageInBackground() ? BACKGROUND_THROTTLE_MS : THROTTLE_MS
  
  // 动态创建限流函数
  if (!throttlers.has(key)) {
    const fn = throttle(
      m => process.send({ type: m.dataType, data: m }),
      currentThrottleMs,
      { leading: true, trailing: true }
    )
    throttlers.set(key, fn)
  }
  
  throttlers.get(key)(msg)
}
```

## 5. 性能瓶颈分析

### 5.1 当前性能瓶颈

#### 数据处理瓶颈
1. **大量位字段解析**: 
   - 问题：bits字段的解析和重建过程复杂
   - 影响：参数序列化时CPU占用高
   - 优化：缓存解析结果，批量处理

2. **频繁的数据序列化**:
   - 问题：每次参数下发都需要完整序列化
   - 影响：UI响应延迟
   - 优化：增量序列化，只处理变更字段

3. **实时数据更新**:
   - 问题：高频单体数据更新可能造成UI卡顿
   - 影响：页面响应性下降
   - 优化：智能限流，后台降频

#### 内存使用瓶颈
1. **协议表缓存**:
   - 问题：table.js中大量协议定义占用内存
   - 影响：应用启动慢，内存占用高
   - 优化：按需加载，分模块缓存

2. **响应式数据开销**:
   - 问题：Vue响应式系统对大对象处理开销大
   - 影响：数据更新性能下降
   - 优化：markRaw、shallowRef的广泛使用

#### 1. 数据处理优化

```javascript
client.on('message', (topic, payload) => {
  // Topic解析：bms/bau/d2s/b1/c1/cell_volt
  const parts = topic.split('/')
  const suffix = parts.at(-1)               // cell_volt
  const blockId = Number(parts[3].slice(1)) // b1 -> 1
  const clusterId = parts.length > 4 ? Number(parts[4].slice(1)) : 0 // c1 -> 1

  // 性能监控
  const tRecv = performance.now()
  const dataType = suffix.toUpperCase()
  const buf = payload
  const len = buf.length
  const hex = buf.toString('hex')

  // 查找解析函数
  const parseFun = TOPIC_TABLE_MAP[suffix]
  if (!parseFun) {
    return // 跳过未知消息
  }

  // 执行解析
  let result
  try {
    result = parseFun(hex)
  } catch (err) {
    console.error(`[PARSE_ERR] ${dataType} len=${len} topic=${topic}`, err)
    return
  }

  const tParsed = performance.now()
  const { baseConfig, data } = result

  // 构建消息对象
  const msg = {
    blockId,
    clusterId,
    dataType: suffix.toUpperCase(),
    topic,
    baseConfig,
    data,
    tRecv,
    tParsed,
    payloadSize: len
  }

  // 发送到主进程（通过限流器）
  sendToParent(msg)
})
```

### 8.2 参数序列化详细实现

#### 序列化核心算法 (useRemoteControlCore.js)
```javascript
export function serializeParameterData(parameterDataFrame, fieldDefinitionTable, startByteOffset, registerCount) {
  // 1. 创建缓冲区
  const totalByteLength = registerCount * 2
  const serializationBuffer = new ArrayBuffer(totalByteLength)
  const bufferDataView = new DataView(serializationBuffer)
  let currentBufferOffset = 0

  // 2. 遍历字段定义表
  let fieldByteOffset = 0
  let matchedParameterFields = []

  for (const parameterField of fieldDefinitionTable) {
    const parameterKey = parameterField.key
    const singleFieldByteSize = getParameterFieldByteSize(parameterField.type)
    const totalFieldByteSize = singleFieldByteSize * (parameterField.count || 1)

    // 3. 检查字段是否在目标范围内
    if (fieldByteOffset >= startByteOffset &&
        fieldByteOffset < startByteOffset + totalByteLength) {

      // 4. 处理数组字段
      if (parameterField.count && parameterField.count > 1) {
        const parameterArray = parameterDataFrame[parameterKey] || []
        for (let elementIndex = 0; elementIndex < parameterField.count; elementIndex++) {
          const elementByteOffset = fieldByteOffset + (elementIndex * singleFieldByteSize)

          if (elementByteOffset >= startByteOffset &&
              elementByteOffset + singleFieldByteSize <= startByteOffset + totalByteLength) {

            const elementValue = parameterArray[elementIndex] || 0
            // 序列化时需要反向缩放，将UI显示值转换为设备原始值
            const deviceValue = parameterField.scale && parameterField.scale > 1
              ? Math.round(elementValue * parameterField.scale)
              : elementValue

            writeParameterFieldValue(bufferDataView, currentBufferOffset, parameterField.type, deviceValue)
            currentBufferOffset += singleFieldByteSize
            matchedParameterFields.push(`${parameterKey}[${elementIndex}]=${elementValue}`)
          }
        }
      }
      // 5. 处理普通字段
      else {
        const parameterValue = parameterDataFrame[parameterKey]
        if (parameterValue !== undefined) {

          // 特殊处理：如果当前字段有bits子字段，需要合并bits值
          if (parameterField.type === 'u16' && hasBitsFields(parameterField.key, fieldDefinitionTable)) {
            const bitsFields = getBitsFields(parameterField.key, fieldDefinitionTable)
            let reconstructedValue = parameterValue || 0

            // 重建父字段值
            for (const bitsField of bitsFields) {
              const bitsValue = parameterDataFrame[bitsField.key]
              if (bitsValue !== undefined) {
                const rawValue = typeof bitsValue === 'object' ? bitsValue.raw : bitsValue
                const mask = ((1 << bitsField.len) - 1) << bitsField.bit
                reconstructedValue = (reconstructedValue & ~mask) |
                                   ((rawValue & ((1 << bitsField.len) - 1)) << bitsField.bit)
              }
            }

            writeParameterFieldValue(bufferDataView, currentBufferOffset, parameterField.type, reconstructedValue)
          } else {
            // 序列化时需要反向缩放
            const deviceValue = parameterField.scale && parameterField.scale > 1
              ? Math.round(parameterValue * parameterField.scale)
              : parameterValue
            writeParameterFieldValue(bufferDataView, currentBufferOffset, parameterField.type, deviceValue)
          }

          currentBufferOffset += singleFieldByteSize
          matchedParameterFields.push(`${parameterKey}=${parameterValue}`)
        }
      }
    }

    fieldByteOffset += totalFieldByteSize
  }

  // 6. 转换为十六进制字符串
  const resultHexString = Array.from(new Uint8Array(serializationBuffer))
    .map(byte => byte.toString(16).padStart(2, '0'))
    .join('')

  console.log(`序列化完成: ${matchedParameterFields.length}个字段, 生成${resultHexString.length/2}字节数据`)
  return resultHexString
}
```

#### 数据接收监控Store (dataReceptionStore.js)
```javascript
export const useDataReceptionStore = defineStore('dataReception', () => {
  // ========== 状态管理 ==========
  const lastDataTime = ref(0)
  const isReceivingData = ref(false)
  const timeoutDuration = ref(5000) // 5秒超时
  const lastMessageType = ref('')
  const currentTime = ref(Date.now())
  const hasReceivedData = ref(false)

  // ========== 数据速率统计 ==========
  const dataRate = ref(0) // KB/s
  const dataAccumulator = ref(0) // 当前秒累加器

  // ========== 计算属性 ==========
  const status = computed(() => {
    if (!mqttStore.isConnected) return 'disconnected'
    if (!hasReceivedData.value) return 'waiting'

    const timeSinceLastData = currentTime.value - lastDataTime.value
    return timeSinceLastData > timeoutDuration.value ? 'timeout' : 'receiving'
  })

  const statusText = computed(() => {
    switch (status.value) {
      case 'disconnected': return 'MQTT未连接'
      case 'waiting': return '等待数据'
      case 'receiving': return '数据正常'
      case 'timeout': return '接收超时'
      default: return '未知状态'
    }
  })

  // ========== 方法 ==========
  function markDataReceived(messageType = 'unknown', dataSize = 0) {
    const now = Date.now()
    const isFirstData = !hasReceivedData.value

    lastDataTime.value = now
    currentTime.value = now
    lastMessageType.value = messageType
    hasReceivedData.value = true
    isReceivingData.value = true

    // 更新数据速率统计
    updateDataRate(dataSize)

    if (isFirstData) {
      // 首次接收数据时，检查是否需要触发配置读取
      checkAndTriggerConfigRead()
    }

    resetTimeout()
  }

  function updateDataRate(newDataSize) {
    dataAccumulator.value += newDataSize
  }

  function calculateDataRate() {
    // 计算速率 (字节/秒 -> KB/秒)
    dataRate.value = Math.round(dataAccumulator.value / 1024 * 10) / 10
    dataAccumulator.value = 0 // 重置累加器
```

```javascript
// 具体解析函数的错误处理
export function parseSysBaseParamRAW(payload) {
  const buf = Buffer.isBuffer(payload)
    ? payload
    : Buffer.from(String(payload).replace(/\s+/g,''), 'hex')

  if (buf.length === 0) return null

  // 失败响应处理
  if (buf.length === 1) {
    const errorCode = buf.readUInt8(0)
    return {
      error: true,
      baseConfig: {},
      data: {
        code: errorCode,
        message: ERROR_CODES[errorCode] || '未知错误'
      }
    }
  }

  // 长度校验
  const dataLen = buf.readUInt16LE(0)
  const paramsBuf = buf.slice(2)
  if (paramsBuf.length !== dataLen) {
    console.warn(`[parseBlockCommonParamRAW] length mismatch: expected ${dataLen}, got ${paramsBuf.length}`)
  }

  try {
    const view = new DataView(paramsBuf.buffer, paramsBuf.byteOffset, paramsBuf.byteLength)
    const { baseConfig } = parseByTable(view, SYS_BASE_PARAM_R)
    return { error: false, data: baseConfig }
  } catch (error) {
    return {
      error: true,
      message: `解析失败: ${error.message}`,
      code: 'TABLE_PARSE_ERROR'
    }
  }
}
```

### 10.2 重试机制实现

#### 智能重试策略
```javascript
// useRetryLogic.js - 通用重试逻辑
export function useRetryLogic(toastService, stopFunction) {
  const retryCount = ref(0)
  const maxRetries = ref(3)
  const retryDelay = ref(2000) // 2秒
  const isRetrying = ref(false)
  const hasResponse = ref(false)

  let retryTimer = null
  let timeoutTimer = null

  const startRetry = () => {
    retryCount.value = 0
    isRetrying.value = true
    hasResponse.value = false

    // 设置超时检查
    timeoutTimer = setTimeout(() => {
      if (!hasResponse.value && retryCount.value < maxRetries.value) {
        executeRetry()
      } else if (!hasResponse.value) {
        // 达到最大重试次数
        handleRetryFailed()
      }
    }, 5000) // 5秒超时
  }

  const executeRetry = () => {
    retryCount.value++

    console.log(`[重试] 第${retryCount.value}次重试...`)

    toastService.add({
      severity: 'warn',
      summary: '重试中',
      detail: `第${retryCount.value}次重试读取参数...`,
      life: 2000
    })

    // 延迟后重试
    retryTimer = setTimeout(() => {
      if (stopFunction) {
        stopFunction() // 停止当前读取
      }

      // 重新开始读取
      setTimeout(() => {
        startMultiTopicReading(allReadTopics)
      }, 500)

      // 设置下次超时检查
      timeoutTimer = setTimeout(() => {
        if (!hasResponse.value && retryCount.value < maxRetries.value) {
          executeRetry()
        } else if (!hasResponse.value) {
          handleRetryFailed()
        }
      }, 5000)

    }, retryDelay.value)
  }

  const markResponse = () => {
    hasResponse.value = true
    isRetrying.value = false

    // 清理定时器
    if (retryTimer) {
      clearTimeout(retryTimer)
      retryTimer = null
    }
    if (timeoutTimer) {
      clearTimeout(timeoutTimer)
      timeoutTimer = null
    }

    if (retryCount.value > 0) {
      toastService.add({
        severity: 'success',
        summary: '重试成功',
        detail: `第${retryCount.value}次重试后成功读取参数`,
        life: 3000
      })
    }
  }

  const handleRetryFailed = () => {
    isRetrying.value = false

    toastService.add({
      severity: 'error',
      summary: '读取失败',
      detail: `重试${maxRetries.value}次后仍然失败，请检查设备连接`,
      life: 5000
    })

    if (stopFunction) {
      stopFunction()
    }
  }

  const cleanup = () => {
    if (retryTimer) {
      clearTimeout(retryTimer)
      retryTimer = null
    }
    if (timeoutTimer) {
      clearTimeout(timeoutTimer)
      timeoutTimer = null
    }
    isRetrying.value = false
  }

  return {
    retryCount,
    maxRetries,
    isRetrying,
    startRetry,
    markResponse,
    cleanup
  }
}
```
