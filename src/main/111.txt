全局枚举与规则（给 Cursor）

实现建议：将下列“枚举名 → {数值: 文本}”注册为字典。事件清单中同名参数（如“堆序号”）一律套用对应字典；若带范围规则（如簇序号 1~20），按规则生成文本。

A. 通用编号枚举

堆序号：{ 1: "第1堆", 2: "第2堆" }

簇序号（范围规则）：n ∈ [1..20] → "第{n}簇"；0xFF → "全部簇"

BMU编号（范围规则）：m ∈ [1..16] → "第{m}BMU"

网卡序号：{ 1: "网卡1", 2: "网卡2" }

B. 状态/开关类

系统状态（静置/充电/放电/开路/自检）：{ 0:"静置", 1:"充电", 2:"放电", 3:"开路", 4:"自检" }

插卡状态：{ 0:"未插卡", 1:"已插卡" }

挂载状态：{ 0:"卸载", 1:"挂载" }

写入状态：{ 0:"SD卡路径不存在", 1:"写成功", 2:"写失败" }

通讯状态：{ 0:"通讯正常", 1:"通讯失联" }

使能状态：{ 0:"不使能", 1:"使能" }

运维模式：{ 0:"非运维模式", 1:"运维模式" }

分簇控制标志：{ 0:"统一控制", 1:"分簇控制" }

网卡速度：{ 0:"100M", 1:"10M" }

接触器自检指令/周期性绝缘检测指令（开关）：{ 0:"关闭", 1:"开启" }

绝缘检测 启停：{ 0x5BB5:"启动", 0x1221:"停止" }

BCP控制：{ 0:"BCP断开", 1:"BCP吸合" }

执行/复位指令（通用 0x5BB5）：{ 0x5BB5:"执行", other:"不执行" }

C. 操作/策略/控制位

下设接触器执行策略 / 堆接触器执行策略：{ 0:"无效（不执行）", 1:"设置充电吸合/BCU充电操作", 2:"设置放电吸合/BCU放电操作", 3:"设置脱离母线/BCU脱离母线", 4:"接触器自检" }

脱离母线原因：
{ 1:"模拟量严重/硬件告警/保留告警", 2:"降功率失败", 3:"在线簇数小于最小并簇数", 4:"烟感急停", 5:"模式切换", 6:"人为断开", 7:"初始上电断开", 8:"EMS与BAU通讯异常", 9:"各簇状态不一致", 10:"退出接触器自检", 11:"启动接触器自检", 12:"停止接触器自检", 13:"无故障且0功率", 14:"一般故障且0功率" }

强制消除/清除故障类型（205/251 通用）：
{ 0:"清除所有故障", 1:"清除充电过流严重告警", 2:"清除放电过流严重告警", 3:"清除绝缘电阻严重告警", 4:"清除接触器黏连（氧化）", 5:"清除PCS通讯故障" }；0xFFFF:"无效"

BCU事件删除数量（207）：0x0000:"不删除", 0xFFFF:"删除全部", other:"删除指定数量"

BAU事件删除数量（268）：同上（设定值/实际删除数量为数字直显）

接触器/IO/高低边位域（201/209/210/211）：按原位说明直显（Bit 位释义文本）

模式设置（203）：{ 0x5BB5:"测试模式", 0x1221:"正常模式" }

掉线检测功能使能（204）：{ 0x5BB5:"开启（默认）", 0x1221:"关闭" }

D. IP/地址类显示规则

IP高/低16位：将“高16位/低16位”合并为 a.b.c.d 显示（可选，若 Cursor 方便处理）。

BMU升级起始地址/数量（261 参数4）：高8位＝起始地址，低8位＝数量 → 可分解两个字段显示。

✅ 给 Cursor 的实现提示（务必照做）

按参数名套用枚举

当参数名精确等于“堆序号”，将 1→第1堆、2→第2堆。

当参数名为“簇序号”，将 n(1..20)→第n簇；0xFF→全部簇。

当参数名为“上一次通讯状态/当前通讯状态”，用“通讯状态”枚举；依此类推。

位域/纯文本

对“位域说明”的参数（如 201/209/210/211/206/252 等），直接显示协议里的汉字说明（不要把位再二次映射）。

复合字段解析（可选增强）

IP高/低16位可合并为 IPv4 展示。

BMU 升级参数（261 参数4）可分解为“起始地址/数量”两个值展示。

缺省处理

遇到未在枚举中出现的数值，原样显示数字，并在文字后加“(未定义)”提示，便于排查。
